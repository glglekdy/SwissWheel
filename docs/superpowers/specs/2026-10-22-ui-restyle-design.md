## 1. 목적과 범위

**목적:** 밋밋한 지금의 모양을 iOS 리퀴드 글래스 느낌으로 바꾸고, Windows 풍선 알림을 앱의 유리 카드로 바꾼다. 레이아웃(휠의 원형 섹터·크기·옵션 패널 위치, 메뉴와 설정 패널의 배치)과 조작은 그대로 둔다.

**이번 범위:**
1. 공용 테마: 유리 한 겹·유리 조각을 그리는 규칙과 팔레트를 한 모듈로
2. 글꼴: Pretendard를 실행 파일에 넣어 모든 화면에 사용
3. 강조색: 프리셋 7개, 기본 블루, 설정에서 변경
4. 새 테마를 휠·옵션 패널·메뉴 바·설정 패널·진행 카드에 적용
5. 자체 알림 카드: 풍선 알림 대체, 진행 카드와 한 창에 쌓기
6. 설정 패널 아래 안내 줄 제거, 키 변경 안내는 알림 카드로
7. 설정 패널에 **알림** 탭, **방해 금지** 설정

**범위 밖:**
- 레이아웃·크기·조작 방식 변경, 아이콘 교체(Segoe Fluent Icons 유지)
- 진짜 굴절(화면 캡처 + 변위 맵). 시안 B안으로 검토했고 A안(실시간 블러 + 광택)으로 정했다.
- 자유 색 지정, Windows 강조색 따라가기, 사용자 글꼴 선택
- Windows "방해 금지"(집중 지원) 상태 감지 — 공개 API가 없다. 대신 앱 설정의 방해 금지로 대신한다.

**성공 기준:**
1. 라이트·다크, 투명 효과 켬·끔, 강조색 7개의 모든 조합에서 휠·옵션 패널·메뉴·설정 패널·카드의 글자가 읽히고 모양이 깨지지 않는다.
2. 한글을 포함한 모든 글자가 Pretendard로 그려진다. Bold는 합성(가짜 굵게)이 아닌 Pretendard Bold 글꼴이다.
3. 앱이 띄우던 모든 풍선 알림이 카드로 뜨고, 카드를 눌러도 다른 창의 포커스를 빼앗지 않는다. 카드를 만들 수 없을 때만 풍선 알림이 뜬다.
4. 휠이 열리는 속도와 드래그 중 반응이 지금과 같다(열림 150ms 이내).
5. 대기 메모리 목표(15MB)를 지킨다.

## 2. 사용자 경험

### 2.1 유리 표현 (A안: 프로스티드 리퀴드 글래스)

모든 표면은 같은 규칙으로 그린다.

- **유리 한 겹 (바탕: 휠 원판, 메뉴 바, 설정 패널, 옵션 패널, 카드):** 시스템 블러(`HostBackdropBrush`, 지금과 같음) → 위에서 아래로 옅어지는 틴트 → 안쪽 광택 → 위쪽 절반 하이라이트 → 반사광 테두리.
- **유리 조각 (휠 칸, 허브, 메뉴 칸, 고른 줄, 고른 탭, 키캡):** 바탕 위에 한 겹 더 올린 반투명 유리. 틴트·안쪽 광택·하이라이트·반사광 테두리를 같은 순서로 그린다.
- **반사광 테두리:** 빛이 왼쪽 위에서 오는 것처럼, 1.3 DIP 선이 왼쪽 위에서 가장 밝고(α .95) 가운데에서 거의 사라졌다가(α .10) 오른쪽 아래에서 다시 조금 밝아진다(α .70). 다크는 각 값의 40%.
- **안쪽 광택:** 도형 가장자리 안쪽으로 번지는 흰 빛. 도형으로 잘라 낸 레이어 안에 폭 2/4/7 DIP 선을 겹쳐 그려 흉내 낸다(블러 효과를 쓰지 않음).
- **강조 조각:** 강조색 틴트(유리 α .85, 불투명 1.0), 흰 글자, 강조색을 밝게 한 안쪽 광택, 강조색 α .45의 은은한 그림자.
- **그림자:** 조각에는 바탕 안쪽으로 떨어지는 짧은 그림자(아래로 3 DIP, 번짐 6). 휠은 창 영역이 원이라(드롭이 원 밖으로 통과해야 함) 원판 바깥 그림자를 그리지 않는다. 메뉴와 카드는 바깥 그림자를 그릴 여백(10 DIP)을 창에 둔다.
- **투명 효과가 꺼져 있으면:** 블러 대신 불투명 판(라이트 `#F2F2F5`, 다크 `#1F1F22`). 광택·테두리·강조는 그대로.
- **테마:** 지금처럼 시스템 앱 테마(라이트/다크)를 따른다. 바뀌면 떠 있는 창도 다시 그린다.

색 토큰 (α는 불투명도):

| 토큰 | 라이트 | 다크 |
|---|---|---|
| 바탕 틴트 (위 → 아래) | `#FFFFFF` .32 → .18 | `#2A2A2E` .55 → `#1C1C1E` .45 |
| 조각 틴트 / 고른 줄 | `#FFFFFF` .30 / .50 | `#FFFFFF` .08 / .14 |
| 안쪽 광택 | `#FFFFFF` .35 | `#FFFFFF` .12 |
| 위쪽 하이라이트 | `#FFFFFF` .35 → 0 (높이의 절반까지) | `#FFFFFF` .10 → 0 |
| 글자 / 보조 글자 | `#1D1D1F` / `#5B5B61` | `#F5F5F7` / `#A1A1A8` |
| 구분선·진행 막대 바탕 | `#000000` .06 / .10 | `#FFFFFF` .08 / .12 |
| 실패 (강조색과 무관) | `#E5484D` | `#E5484D` |

### 2.2 글꼴

- Pretendard v1.3.9 정적 글꼴 세 개(Regular, SemiBold, Bold)를 수정 없이 실행 파일에 넣는다.
- 쓰임: 본문 Regular, 라벨·줄 이름·탭 SemiBold, 값·제목·허브의 포맷 이름·카드 제목 Bold. 크기는 지금 값을 유지한다.
- 실행 파일이 약 4.7MB 커진다(지금 약 9.5MB). 공식 Std 판은 한글이 없어 쓸 수 없고, 우리가 글자를 덜어 내면 OFL의 예약 이름 조항 때문에 "Pretendard"라는 이름을 쓸 수 없으므로 원본을 그대로 넣는다.
- 아이콘은 지금처럼 Segoe Fluent Icons(Windows 10은 Segoe MDL2 Assets).

| `purple` | 퍼플 | `#7D5BF0` |
| `pink` | 핑크 | `#E0457F` |
| `red` | 레드 | `#E5484D` |
| `orange` | 오렌지 | `#E0680B` |
| `green` | 그린 | `#1E9E50` |
| `graphite` | 그래파이트 | `#5C5C64` |

- 모두 흰 글자가 읽히도록 밝기를 맞췄다. 쓰이는 곳: 휠의 커서 칸, 옵션 패널의 커서 줄, 메뉴 바의 고른 칸, 설정 패널의 값 옆 색 점, 진행 막대, 트레이 진행 링, 완료 카드의 아이콘·"클릭하면 폴더 열기".
- 설정의 ◀ ▶ 순서는 표의 순서이고, 끝에서의 동작은 다른 목록형 설정(영상 압축 등)과 같다.

### 2.4 화면별

- **휠:** 원판은 유리 한 겹, 칸·허브는 유리 조각. 칸 모서리 9 DIP(지금 6), 칸 사이 간격 4 DIP 유지. 커서 칸은 강조 조각이 되고 지금처럼 6 DIP 커진다(120ms). 허브의 포맷 이름은 Bold 14, 휠 이름은 SemiBold 10.5.
- **옵션 패널:** 유리 한 겹, 모서리 16 DIP. 커서 줄은 강조 조각, 기본값 줄에는 작은 "기본" 배지(조각 틴트 위 보조 글자).
- **메뉴 바:** 유리 한 겹, 모서리 22 DIP. 칸은 유리 조각(모서리 16), 고른 칸만 강조 조각. 커서가 올라간 칸은 조각 틴트를 고른 줄 값(라이트 .50)으로.
- **설정 패널:** 유리 한 겹, 모서리 20 DIP.
  - 탭은 iOS식 분할 버튼: 탭 줄 전체가 옅은 홈(구분선 색), 고른 탭은 밝은 알약(라이트 흰색 .85, 다크 흰색 .18)과 진한 글자. 지금의 밑줄은 없앤다.
  - 고른 줄은 고른 줄 틴트의 유리 조각(모서리 11). 값 줄의 ◀ ▶는 보조 글자색 작은 갈매기표.
  - 키 값은 키캡 모양 유지(라이트 흰색 .80 + 아래쪽 안쪽 그림자, 다크 흰색 .12).
  - **안내 줄을 없앤다.** 키 입력 대기와 그 결과는 알림 카드(2.6)로 보낸다. 설정 파일 오류 줄("설정 파일에 오류가 있어 저장하지 않습니다")은 상태 표시라 패널 위쪽에 그대로 둔다.
- **진행 카드:** 알림 카드와 같은 모양(2.6). 제목 "변환 중 · N개", 줄마다 "이름 → 포맷", 강조색 진행 막대(5 DIP, 둥근 끝), % 또는 "대기". 최대 5줄, 나머지는 "외 N개"(지금과 같음).

### 2.5 설정 탭

| 탭 (왼쪽부터) | 줄 |
|---|---|
| 단축키 | 휠 열기 키, 휠 전환 키, 취소 키 |
| 도구 | 축소 비율, 영상 압축 |
| 변환 | JPG 품질, WebP 품질, MP3 비트레이트 |
| **알림** (새 탭) | 진행률 카드, 트레이 링, **방해 금지** |
| 일반 | Windows 시작 시 실행, **강조색** |

- 진행률 카드·트레이 링은 일반에서 알림으로 옮긴다. 줄은 탭마다 최대 3개(`MAX_ROWS` 유지). 안내 줄이 빠지므로 패널은 한 줄(36 DIP)만큼 짧아진다.
- 저장: `[appearance] accent = "blue"`, `[notifications] do_not_disturb = false`. 둘 다 없으면 기본값. 잘못된 값이면 기본값으로 그리고, 지금의 설정 오류 처리와 같이 파일을 덮어쓰지 않는다.

### 2.6 알림 카드

**모양:** 폭 300 DIP, 모서리 18, 안쪽 여백 12/14, 유리 한 겹. 왼쪽에 지름 30의 원형 아이콘(완료 = 강조색 ✓, 실패 = 빨강 ⚠, 정보 = 강조색 ⓘ, 키 = 흰 조각 ⌨), 오른쪽에 제목(Bold 13.5) · 본문(Regular 12, 보조 글자, 최대 2줄, 넘치면 …) · 행동 줄(SemiBold 11.5, 강조색, 누르면 하는 일이 있을 때만). 자동으로 닫히는 카드는 아래에 남은 시간을 보여 주는 2 DIP 막대.

**위치와 쌓기:**
- 주 모니터 작업 영역의 오른쪽 아래, 가장자리에서 12 DIP(지금 진행 카드 자리).
- 진행 카드는 항상 맨 아래. 알림은 그 위로 쌓이고, 새 알림이 진행 카드에 가장 가깝다. 카드 사이 8 DIP.
- 알림은 한 번에 최대 3개. 넘치면 가장 오래된 것이 바로 닫힌다.
- 나타날 때 오른쪽에서 밀려 들어오며 페이드(200ms), 닫힐 때 페이드(150ms), 남은 카드는 제자리로 미끄러진다.

**종류:**

| 상황 | 아이콘 · 제목 | 닫히는 때 | 누르면 |
|---|---|---|---|
| 작업 완료 | ✓ "N개 파일을 PNG로 변환했습니다" (지금 풍선의 문구) | 5초 | 결과 폴더를 열고 그 작업의 첫 결과 파일 선택 |
| 작업 실패(일부 포함) | ⚠ 지금 풍선의 문구(첫 오류 요약, 성공 개수) | 8초 | 결과가 있으면 그 폴더, 없으면 닫기만 |
| 업데이트·다운로드·재시작 등 앱의 다른 알림 | ⓘ 또는 ⚠ (지금 `notify`/`warn` 구분) | 5초 / ⚠ 8초 | 닫기만 |
| 키 입력 대기 | ⌨ "바꿀 키를 누르세요", 본문 "<줄 이름> · 다른 곳을 클릭하면 취소" | 키 입력·취소·5초 시간 초과(지금의 `CAPTURE_TIMEOUT`, 막대가 이 시간을 보여 줌) | 닫고 키 입력 취소 |
| 키 변경 결과 (쓸 수 없는 키, 맞바꿈) | ⓘ 지금 안내 줄에 쓰던 문구 | 3초 | 닫기만 |

- **카드 아무 데나 누르면** 할 일을 하고 닫힌다. 닫기(×) 버튼은 없다.
- 커서가 카드 위에 있는 동안 그 카드의 시간이 멈춘다.
- 카드마다 자기 결과 경로를 가진다(지금의 "마지막 결과 하나" 대신).
- **진행 카드 → 결과 카드:** 마지막으로 돌던 작업이 끝나고 진행 카드가 보이는 중이면, 진행 카드 자리가 그 작업의 결과 카드로 바뀐다(높이가 200ms 동안 바뀜). 다른 작업이 아직 돌면 결과는 위에 새 카드로 뜬다. 진행률 카드 설정이 꺼져 있으면 결과 카드만 뜬다.
- **포커스:** 카드 창은 활성화되지 않는다. 카드 부분만 클릭을 받고, 카드 밖(창 영역 밖)은 아래 창으로 통과한다.

**조용히 있어야 할 때:**
- `SHQueryUserNotificationState`가 전체 화면(`QUNS_BUSY`, `QUNS_RUNNING_D3D_FULL_SCREEN`)이나 프레젠테이션 모드(`QUNS_PRESENTATION_MODE`)면 카드 창 전체(진행 카드 포함)를 숨기고 새 알림은 모아 둔다. 2초마다 다시 확인해 풀리면 모아 둔 것 중 최근 3개를 보여 준다. 모여 있던 시간은 자동 닫힘 시간에 들어가지 않는다.
- **방해 금지(설정):** 켜져 있으면 **작업 완료·실패 카드**를 띄우지 않고 버린다(모아 두지 않음). 나머지 알림 — 업데이트·다운로드·재시작 칸의 결과와 그 뒤 시작할 때의 완료 알림, 설정 파일 오류, "다음 버전에서 지원 예정입니다", 키 변경 안내 — 은 사용자가 직접 한 조작의 응답이거나 놓치면 안 되는 것이라 그대로 뜬다. 진행 카드와 트레이 링은 각자의 설정을 따른다. 버린 결과는 로그에 남고, 트레이 툴팁에 마지막 작업 결과("마지막 작업: …")를 보여 준다.

## 3. 구조

### 3.1 `swisswheel-core`

- `appearance.rs` (새): `Accent` 열거형(2.3의 7개, 순서·이름·표시·색 값), `next/prev`, TOML 이름 변환.
- `config.rs`: `appearance.accent`, `notifications.do_not_disturb` 추가. 기본값과 잘못된 값 처리.
- `settings.rs`: `Category::Notifications`("알림", 변환과 일반 사이), `SettingItem::Accent`·`DoNotDisturb`, 2.5의 줄 배치, `step`·값 표시.
- `menu.rs`: `hint()`와 그 문구 제거. 키 입력 대기의 시작·끝은 앱이 알림으로 띄울 수 있게 지금처럼 동작(`MenuAction::StartCapture` 등)으로 알린다.
- `menu_geometry.rs`: `hint` 상자 제거, 패널 높이 = 알림 줄(있으면) + 탭 + `MAX_ROWS` 줄. 탭 수만큼 탭 상자.
- `notices.rs` (새, 순수 로직): 카드 목록과 규칙. 시각은 인자로 받는다.
  - `post(kind, title, body, action, now)`, `progress_changed(rows, now)`, `job_finished(report_notice, last_job, now)`
  - `hover(Option<id>, now)`, `click(id) -> Option<NoticeAction>`, `tick(now) -> 바뀜 여부`
  - `set_quiet(bool, now)` (전체 화면 등), 방해 금지 필터
  - 쌓는 순서, 최대 3개, 종류별 시간, 멈춤, 진행 → 결과 전환, 모아 두기와 최근 3개
  - 결과: 그릴 카드 목록(종류, 문구, 남은 시간 비율, 애니메이션 진행도)

### 3.2 `swisswheel` (앱)

- `theme.rs` (새): `wheel::render`의 `Palette`·`palette()`·`light_theme()`·`transparency_enabled()`를 옮기고 2.1의 토큰과 강조색을 더한다. `Theme { light, glass, accent, alpha }`에서 색을 꺼낸다.
  - `glass_layer(ctx, geometry, theme)`, `glass_piece(ctx, geometry, theme, style)` — 2.1의 순서대로 그리는 공용 함수. 휠·메뉴·카드가 모두 이것만 쓴다.
- `fonts.rs` (새): `include_bytes!`로 넣은 세 글꼴을 `IDWriteFactory5::CreateInMemoryFontFileLoader` → `CreateInMemoryFontFileReference`(정적 바이트를 소유 객체와 함께 넘겨 복사하지 않음) → `IDWriteFontSetBuilder1` → `CreateFontCollectionFromFontSet`으로 등록. UI 스레드에서 한 번 만들어 모든 표면이 같은 공유 팩토리와 컬렉션을 쓴다. 실패하면 `None`, 그리면 지금처럼 `Segoe UI Variable Text`(시스템 컬렉션).
- `surface.rs`: 텍스트 형식을 `fonts`의 컬렉션으로 만든다. 휠도 이 경로를 쓴다.
- `wheel/render.rs`, `menubar/render.rs`: `theme`의 함수로 다시 그린다. 레이아웃 계산은 그대로.
- `notice.rs` (새, `progress.rs` 대체): 카드 창 하나.
  - `WS_EX_TOPMOST | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`, `WM_MOUSEACTIVATE` → `MA_NOACTIVATE`.
  - 창 영역(`SetWindowRgn`) = 카드들의 둥근 사각형 + 그림자 여백. 카드가 없으면 숨김.
  - 마우스: 카드 히트 테스트, `TrackMouseEvent`로 떠남 감지, 클릭은 `notices::click`.
  - 애니메이션 동안만 타이머(16ms), 그 밖에는 다음 닫힘 시각에 한 번.
  - 2초 타이머로 `SHQueryUserNotificationState` 확인(모아 둔 알림이 있거나 카드가 떠 있을 때만).
- `tray.rs`: `notify`/`warn`은 남기되 앱 코드는 부르지 않는다. 카드 창을 만들 수 없을 때 `notice`가 대신 부른다. 툴팁에 "마지막 작업" 줄.
- `app.rs`: 모든 `tray.notify`/`tray.warn` 호출(지금 22곳)을 알림 카드로. `last_output`·`NIN_BALLOONUSERCLICK` 처리는 카드의 행동으로 대체(풍선 대체 시에만 유지). 키 입력 대기의 시작·결과·끝을 카드로. 설정의 강조색·방해 금지가 바뀌면 떠 있는 창을 다시 그린다.
- 디버그: 환경 변수 `SWISSWHEEL_FORCE_BALLOON=1`이면 카드 창을 만들지 않는다(풍선 대체 확인용).

### 3.3 자산과 라이선스

- `assets/fonts/Pretendard-Regular.otf`, `Pretendard-SemiBold.otf`, `Pretendard-Bold.otf`(v1.3.9 릴리스의 `public/static`), `assets/fonts/OFL.txt`(릴리스의 LICENSE 전문).
- README의 라이선스 절에 "Pretendard — SIL Open Font License 1.1, 수정 없이 포함"을 적는다.

## 4. 오류 처리

| 상황 | 동작 |
|---|---|
| 글꼴 등록 실패 (오래된 Windows 등) | Segoe UI로 그림, 로그 한 줄 |
| 카드 창 생성 실패 / D2D 장치 손실 후 복구 실패 | 같은 문구를 풍선 알림으로, 로그 |
| `accent`·`do_not_disturb` 값이 잘못됨 | 기본값으로 동작, 파일은 덮어쓰지 않음(지금의 설정 오류 처리) |
| 카드의 결과 폴더가 그새 지워짐 | 탐색기가 여는 데 실패해도 카드는 닫히고 로그만 |
| 전체 화면 확인 API 실패 | 조용하지 않은 것으로 간주(카드 표시) |
| 테마·투명 효과·DPI가 바뀜 | 떠 있는 창을 다시 배치하고 다시 그림 |

## 5. 테스트

**자동 (`cargo test --workspace`):**
- `appearance`: 7개 순서, 앞뒤 이동, TOML 이름 왕복, 모르는 이름.
- `config`: 두 새 키의 기본값·읽기·쓰기, 잘못된 값, 사용자 주석 보존(지금의 저장 방식).
- `settings`: 다섯 탭과 줄 배치, 모든 탭이 `MAX_ROWS` 이하, `Accent`·`DoNotDisturb`의 `step`·표시.
- `menu`, `menu_geometry`: 안내 줄 제거 후 패널 높이, 다섯 탭 상자, 히트 테스트.
- `notices`: 쌓는 순서, 3개 초과 시 가장 오래된 것 닫힘, 종류별 시간, 멈춤과 재개, 클릭의 행동, 진행 → 결과 전환(마지막 작업일 때만), 진행률 카드 꺼짐, 조용한 동안 모으기와 풀릴 때 최근 3개·시간 미포함, 방해 금지가 거르는 것과 통과시키는 것, 카드별 경로, 키 입력 대기의 시작·입력·취소·시간 초과.
- `fonts` (앱, Windows에서): 컬렉션에서 "Pretendard"를 Regular·SemiBold·Bold로 찾고, Bold의 글꼴 면에 합성(`DWRITE_FONT_SIMULATIONS_BOLD`)이 없으며, 한글 글자(가, 똠, 뷁)가 들어 있다.

**직접 확인 (`docs/manual-test.md`에 추가):**
- 라이트·다크 × 투명 효과 켬·끔 × 강조색 7개: 휠(칸 6개, 칸 24개), 옵션 패널, 메뉴 바, 설정 패널 다섯 탭, 진행 카드, 알림 카드.
- 카드: 포커스를 빼앗지 않음(메모장에 입력하면서 작업 끝내기), 누르면 폴더 열기와 닫힘, 커서 올리면 멈춤, 넷째 알림이 오면 가장 오래된 것 닫힘, 진행 → 결과 전환, 카드 밖 클릭 통과.
- 전체 화면 게임·프레젠테이션 중에 작업 끝내기 → 카드 안 뜸 → 빠져나오면 뜸.
- 방해 금지 켜고 작업 끝내기(성공·실패 모두 안 뜸, 툴팁에 결과) / 업데이트 칸 누르기(뜸).
- `SWISSWHEEL_FORCE_BALLOON=1`로 풍선 대체.
- 고DPI(150%, 200%)와 두 모니터.
- 대기 메모리(작업 관리자 "메모리") 15MB 이내.

## 6. 구현 순서

한 계획 안에서 세 단계로 나누고, 단계마다 앱이 동작하는 상태로 커밋한다.

1. **바탕:** `appearance`·설정 키·알림 탭, `fonts`, `theme`(아직 옛 모양을 내도록), 테스트.
2. **새 모양:** 휠·옵션 패널·메뉴 바·설정 패널·진행 카드를 새 테마와 Pretendard로.
3. **알림 카드:** `notices`, `notice` 창, 풍선 대체, 안내 줄 제거와 키 안내, 방해 금지, 툴팁.
