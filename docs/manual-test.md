# 수동 테스트 체크리스트

자동 테스트(`cargo test --workspace`)로 확인할 수 없는 화면·입력·셸 연동을 확인한다. 릴리스 빌드(`cargo build --release -p swisswheel`)의 `target/release/swisswheel.exe`로 수행한다.

준비: 테스트 폴더에 PNG 몇 개(투명 배경 PNG 1개 포함), 확장자만 맞춘 가짜 파일 `노래.flac`, `영상.mp4`를 둔다. 휠 동작은 확장자로만 판단하므로 M1~M12는 가짜 파일로 충분하다. M13~M16은 진짜 미디어가 필요하다: `ffmpeg -f lavfi -i testsrc=duration=60:size=1280x720:rate=30 -f lavfi -i sine=duration=60 -c:v libx264 -c:a aac -shortest 긴영상.mp4`, `ffmpeg -f lavfi -i sine=duration=5 -c:a flac 진짜노래.flac`, `ffmpeg -f lavfi -i testsrc=duration=2:size=241x181:rate=10 움짤.gif`로 만들 수 있다. FFmpeg가 PATH에 있거나 `swisswheel.exe` 옆 `ffmpeg` 폴더에 있어야 한다.

업데이트 시험 준비 (M40~M46, 저장소 공개 전): 빈 폴더 `app`에 `cargo build`한 `target\debug\swisswheel.exe`를 복사한다. 다른 폴더 `srv`에 같은 exe를 복사하고 끝에 아무 바이트나 덧붙인다(새 버전 대신). `srv`에 `swisswheel.exe.sha256`(`<소문자 해시>  swisswheel.exe`)과 파일 `latest`(`{"tag_name":"v9.0.0","html_url":"https://github.com/glglekdy/SwissWheel/releases","body":"시험","assets":[{"name":"swisswheel.exe","browser_download_url":"http://127.0.0.1:8765/swisswheel.exe"},{"name":"swisswheel.exe.sha256","browser_download_url":"http://127.0.0.1:8765/swisswheel.exe.sha256"}]}`)을 둔다. `srv`에서 `python -m http.server 8765 --bind 127.0.0.1`. 실행 중인 SwissWheel을 끄고, `SWISSWHEEL_UPDATE_URL=http://127.0.0.1:8765/latest`와 `SWISSWHEEL_PREVIEW=update`를 넣고 `app\swisswheel.exe`를 실행한다(메뉴의 업데이트 타일을 누른 것과 같다. 다른 미리보기와 달리 단일 인스턴스 규칙과 시작 시 실행 처리는 평소대로 한다). 새로 켜진 앱도 같은 환경 변수를 물려받아 확인 창을 한 번 더 띄우는데, "아니요"를 누르면 된다. "Windows 시작 시 실행"이 켜져 있으면 시험용 exe가 시작 프로그램 등록을 자기 경로로 바꾸므로, 시험 뒤 원래 `swisswheel.exe`를 한 번 실행해 되돌린다.

## UI 리디자인

디버그 빌드의 미리보기 `SWISSWHEEL_PREVIEW`(`panel`, `panel-left`, `menu*`, `notices`)로 화면을 띄워 확인할 수 있다. 아래는 설계 문서 5절의 직접 확인 목록이다.

- 라이트·다크 × 투명 효과 켬·끔 × 강조색 7개: 휠(칸 6개, 칸 24개), 옵션 패널, 메뉴 바, 설정 패널 다섯 탭, 진행 카드, 알림 카드.
- 카드: 포커스를 빼앗지 않음(메모장에 입력하면서 작업 끝내기), 누르면 폴더 열기와 닫힘, 커서 올리면 멈춤, 넷째 알림이 오면 가장 오래된 것 닫힘, 진행 → 결과 전환, 카드 밖 클릭 통과.
- 전체 화면 게임·프레젠테이션 중에 작업 끝내기 → 카드 안 뜸 → 빠져나오면 뜸.
- 방해 금지 켜고 작업 끝내기(성공·실패 모두 안 뜸, 툴팁에 결과) / 업데이트 칸 누르기(뜸).
- `SWISSWHEEL_FORCE_BALLOON=1`로 풍선 대체.
- 고DPI(150%, 200%)와 두 모니터.
- 대기 메모리(작업 관리자 "메모리") 15MB 이내.
