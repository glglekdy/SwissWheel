# 수동 테스트 체크리스트

자동 테스트(`cargo test --workspace`)로 확인할 수 없는 화면·입력·셸 연동을 확인한다. 릴리스 빌드(`cargo build --release -p swisswheel`)의 `target/release/swisswheel.exe`로 수행한다.

준비: 테스트 폴더에 PNG 몇 개(투명 배경 PNG 1개 포함), 확장자만 맞춘 가짜 파일 `노래.flac`, `영상.mp4`를 둔다. 휠 동작은 확장자로만 판단하므로 M1~M12는 가짜 파일로 충분하다. M13~M16은 진짜 미디어가 필요하다: `ffmpeg -f lavfi -i testsrc=duration=60:size=1280x720:rate=30 -f lavfi -i sine=duration=60 -c:v libx264 -c:a aac -shortest 긴영상.mp4`, `ffmpeg -f lavfi -i sine=duration=5 -c:a flac 진짜노래.flac`, `ffmpeg -f lavfi -i testsrc=duration=2:size=241x181:rate=10 움짤.gif`로 만들 수 있다. FFmpeg가 PATH에 있거나 `swisswheel.exe` 옆 `ffmpeg` 폴더에 있어야 한다.

| ID | 절차 | PASS 조건 |
|---|---|---|
| M1 | 탐색기에서 PNG를 드래그하다가 마우스를 멈추고 Space | 커서 위치에 휠이 지연 없이 나타나고 바깥 칸에 포맷(JPG, WEBP …)이 보임 |
| M2 | 휠이 열린 상태에서 Tab 반복. `노래.flac`으로도 반복 | PNG: 변환 → 도구 → 동작 → 변환. FLAC: 도구 휠을 건너뜀 (변환 → 동작) |
| M3 | 칸 위로 커서 이동, 이어서 가운데 원으로 이동 | 칸이 빨갛게 강조되고 살짝 커짐. 가운데에서는 드롭 금지 커서 |
| M4 | PNG를 JPG 칸에 드롭, 알림 클릭 | 같은 폴더에 `이름.jpg`, 알림 "JPG 변환 완료", 클릭하면 탐색기가 결과 파일을 선택해서 열림 |
| M5 | M4 직후 5초 기다린 뒤 원본 확인. 같은 드라이브 안 드래그와 Shift 드래그 모두 | 원본 PNG가 그대로 있음 |
| M6 | 같은 파일을 연달아 두 번 JPG로 | `이름.jpg`, `이름 (1).jpg` |
| M7 | 메모장 제목 표시줄을 드래그하면서 Space를 길게 누름. 메모장에서 글자를 드래그로 선택하면서 Space | 휠이 전혀 보이지 않음. 글자 선택 중의 Space는 메모장에 입력됨 |
| M8 | 휠을 연 뒤 Esc를 누르고 다른 폴더에 놓기. 휠을 연 뒤 휠 밖에서 놓기 | Esc: 휠만 닫히고 드래그는 계속되어 정상 이동. 휠 밖: 원래 대상에 정상 드롭 |
| M9 | 화면 오른쪽 아래 구석에서 휠 열기. (선택) 디스플레이 배율 125%/150%에서 반복 | 휠이 화면 안으로 밀려 들어와 잘리지 않음. 배율을 바꿔도 크기와 칸 판정이 그림과 일치 |
| M10 | 설정 → 개인 설정 → 색에서 앱 모드를 다크/라이트로 바꾼 뒤 휠 열기 | 휠 배경과 글자색이 테마를 따름 |
| M11 | 가짜 `영상.mp4`를 MP3 칸에 드롭 | 경고 알림 "영상.mp4: 영상·오디오 파일을 읽을 수 없습니다", 폴더에 결과·임시 파일 없음 |
| M12 | 휠을 몇 번 열고 1분 대기한 뒤 작업 관리자 → 세부 정보 → "메모리(활성 개인 작업 집합)" | 15MB 이하 |
| M13 | `긴영상.mp4`를 WEBM 칸에 드롭하고 트레이 아이콘에 마우스를 올려 둠 | 툴팁이 "SwissWheel · 작업 중 1개 · N%"로 바뀌고 N이 오름. 끝나면 "SwissWheel"로 돌아가고 완료 알림 |
| M14 | `긴영상.mp4`를 WEBM으로 보내고 몇 초 뒤 트레이 → 종료 | 수 초 안에 종료. 작업 관리자에 ffmpeg.exe 없음. 폴더에 `.swisswheel-tmp`·`긴영상.webm` 없음 |
| M15 | `진짜노래.flac`을 MP3 칸에 드롭, 알림 클릭 | "MP3 변환 완료", 클릭하면 결과 파일이 선택된 탐색기. 재생됨 |
| M16 | `움짤.gif`(홀수 크기)를 MP4 칸에 드롭 | `움짤.mp4`가 생기고 재생됨 |
